## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS is generally considered to offer one of the broadest selections of cloud services among the three major providers. Its platform covers computing, storage, networking, databases, security, analytics, artificial intelligence, and many other areas, allowing organizations to build a wide variety of solutions on one platform.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already depend heavily on Microsoft technologies. Azure integrates closely with products and services such as Microsoft 365, Microsoft Entra, Windows Server, Dynamics 365, and other parts of the Microsoft ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for organizations focused on Artificial Intelligence, Machine Learning, and Kubernetes. Google Cloud provides GKE for managed Kubernetes and continues to develop infrastructure and services specifically for AI workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **Google Cloud** because I am interested in modern technologies such as Artificial Intelligence, data analytics, and Kubernetes. Google Cloud provides strong tools for these areas while also offering the core computing, storage, and networking services needed to build and deploy cloud applications.

## Multi-Cloud Decision Matrix

| Business Requirement        | Recommended Platform | Justification                                                                                                               |
| --------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Startup Company**         | AWS                  | AWS provides a broad service selection and flexible infrastructure that can support a startup as it grows.                  |
| **Enterprise Organization** | AWS                  | AWS provides extensive enterprise services, security capabilities, and global infrastructure for large workloads.           |
| **Microsoft Environment**   | Azure                | Azure integrates closely with Microsoft's identity, productivity, server, and enterprise technologies.                      |
| **AI / Machine Learning**   | Google Cloud         | Google Cloud has strong AI infrastructure and services designed for machine learning and AI workloads.                      |
| **Kubernetes Deployment**   | Google Cloud         | Google Kubernetes Engine provides a managed Kubernetes platform with strong support for cloud-native workloads.             |
| **Global Web Application**  | AWS                  | AWS provides broad global infrastructure and a large selection of services for deploying highly available web applications. |

## Conclusion

AWS, Azure, and Google Cloud all provide the fundamental building blocks needed to develop and operate cloud applications. However, each platform has different strengths. AWS is a strong general-purpose option with a broad service ecosystem, Azure is particularly suitable for Microsoft-based organizations, and Google Cloud is especially attractive for AI, analytics, and Kubernetes-focused workloads.
