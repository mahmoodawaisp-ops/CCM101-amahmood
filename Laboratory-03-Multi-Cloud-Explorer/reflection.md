# Mission 3 Reflection

This laboratory activity helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. Each provider has different strengths, services, and capabilities that can be matched to specific business requirements.

The cloud platform that impressed me the most was **Google Cloud Platform (GCP)**. I found its strengths in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes especially interesting. These capabilities make GCP a strong option for organizations working with modern technologies and large amounts of data.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, networking, identity and access management, databases, and other services needed to build and operate cloud applications. They also provide global infrastructure, management consoles, scalability, and security features that allow organizations to deploy applications without maintaining all of their physical infrastructure.

Business requirements have a major influence on cloud platform selection. Factors such as budget, existing technology, performance, scalability, security, location, and the type of application all need to be considered. For example, Azure can be a strong choice for an organization already using Microsoft technologies, while GCP may be better suited to an AI or Kubernetes-focused organization.

Acting as a Cloud Solutions Consultant taught me to look beyond individual services and think about the actual needs of a client. I learned that a good cloud recommendation should connect technical capabilities with business goals.

My GitHub Cloud Computing Portfolio has also improved after completing this mission. It now contains organized research, comparisons, client recommendations, decision matrices, Linux investigation results, screenshots, and reflections. This makes the repository more useful as a record of my practical Cloud Computing learning throughout the semester.
