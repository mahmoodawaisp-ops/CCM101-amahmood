# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform operated by Amazon. AWS was launched in 2006 and provides a broad range of cloud services that organizations can use to build, deploy, store, manage, and scale applications and IT infrastructure.

AWS supports startups, small businesses, large enterprises, government organizations, and other institutions. Its services use a pay-as-you-go model, allowing organizations to provision cloud resources without purchasing and maintaining all of the underlying physical infrastructure themselves.

## Global Infrastructure

AWS has a large global infrastructure designed to provide scalability, reliability, and low-latency access to cloud resources.

AWS organizes its infrastructure into geographic **Regions**, which contain multiple isolated **Availability Zones (AZs)**. Each AWS Region has at least three Availability Zones, helping organizations design applications with higher availability and resilience.

As of 2026, AWS lists **39 geographic Regions and 123 Availability Zones**. AWS also provides additional infrastructure options such as Local Zones and edge locations for workloads that need lower latency or services closer to end users.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services.

Through the console, users can:

* Launch and manage cloud resources.
* Select and work with different AWS Regions.
* Manage users and permissions.
* Monitor applications and service usage.
* View billing and account information.
* Access and configure AWS services from one interface.

The console provides a central way for administrators, developers, and cloud engineers to manage AWS resources without relying only on command-line tools.

## Four Core AWS Services

### 1. Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides resizable virtual computing capacity in the AWS Cloud. Organizations can launch virtual servers called instances and select different operating systems, instance types, networking options, and storage configurations.

**Common uses:**

* Hosting websites and applications
* Running backend systems
* Development and testing
* Enterprise workloads
* High-performance computing

### 2. Amazon S3

**Amazon Simple Storage Service (S3)** is an object storage service designed to store and retrieve large amounts of data. Data is stored as objects inside containers called buckets.

**Common uses:**

* Backup and archival
* Application data storage
* Data lakes
* Static website content
* Media and file storage

### 3. Amazon VPC

**Amazon Virtual Private Cloud (VPC)** allows organizations to create logically isolated networking environments in AWS. It provides control over network configuration, IP addressing, subnets, routing, and security.

**Common uses:**

* Building private cloud networks
* Controlling network access
* Connecting application components
* Creating secure enterprise environments

### 4. AWS Identity and Access Management (IAM)

**AWS Identity and Access Management (IAM)** controls authentication and authorization for AWS resources. It allows administrators to create identities and policies that determine which users or systems can access specific resources and actions.

**Common uses:**

* Managing user access
* Applying permissions
* Protecting AWS resources
* Implementing least-privilege access

## Three Advantages of AWS

### 1. Extensive Service Selection

AWS provides a very broad collection of cloud services covering areas such as computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

### 2. Global Infrastructure

AWS provides infrastructure across many geographic locations, allowing organizations to deploy applications closer to their users and design systems for availability and resilience.

### 3. Scalability and Flexibility

AWS allows organizations to provision and adjust cloud resources according to their workload requirements. This makes it possible to scale applications as demand changes without having to purchase additional physical servers.

## Typical Enterprise Use Cases

AWS is used across many industries and business environments. Typical enterprise use cases include:

* Hosting business applications and websites
* Migrating traditional infrastructure to the cloud
* Backup and disaster recovery
* Data storage and analytics
* Artificial Intelligence and Machine Learning workloads
* Software development and testing
* E-commerce platforms
* Enterprise application modernization
* Global application deployment

## Summary

AWS provides a comprehensive cloud platform with a large global infrastructure and a wide range of services. Its combination of computing, storage, networking, identity management, scalability, and global deployment options makes it suitable for organizations with many different technical and business requirements.
