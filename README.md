# Mission 1: Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using the KillerCoda Playground. As part of the mission, I explored the Linux environment, gathered basic system information, organized files and directories, and began building my Cloud Computing portfolio using GitHub.

## Objectives

* Access and use a cloud-based Linux environment through KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a professional GitHub repository.
* Document technical work using Markdown.
* Practice proper technical documentation.

## Activities Performed

During this laboratory activity, I:

* Launched an Ubuntu 24.04 environment using KillerCoda.
* Created and logged into my own Linux user account.
* Verified my username, working directory, and hostname.
* Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
* Created and organized the required folders and Markdown files.
* Created `system-information.md`.
* Created `about-me.md` inside the `Notes` folder.
* Created my public GitHub repository for the Cloud Computing portfolio.

## Skills Learned

Through this laboratory activity, I learned how to work with a cloud-based Linux environment and use basic Linux commands to inspect and organize a system. I also improved my skills in creating Markdown documentation, organizing project files, and using GitHub as a platform for maintaining a technical portfolio.

This activity provided practical experience that will help me with the upcoming Cloud Computing laboratory activities throughout the semester.
