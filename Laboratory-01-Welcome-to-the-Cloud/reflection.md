# Reflection

This laboratory activity gave me my first hands-on experience working with a cloud-based Linux environment using KillerCoda. I learned how to access the environment, create and use a Linux user account, and navigate the system using basic commands.

I also learned how to gather system information such as the Linux distribution, kernel version, CPU information, memory, and disk space. Creating and organizing Markdown files helped me understand the importance of keeping technical information clear and organized.

Another important part of the activity was creating my GitHub Cloud Computing Portfolio. I learned that GitHub can be used to store, organize, and document my laboratory activities throughout the semester.

Overall, this activity helped me become more comfortable with Linux, Markdown, and GitHub. I believe these skills will be useful as I continue learning about cloud computing and other technologies.
